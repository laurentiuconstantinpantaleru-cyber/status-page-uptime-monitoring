Checks

Each monitor points at one URL. A worker checks it every 5 minutes by default; an admin can pick any interval from 1 to 60 minutes. A check waits up to 30 seconds for an answer, long enough for a sleeping free host to wake up.

HTTP status

The answer must have the expected status code, 200 unless the monitor says otherwise. A 5xx or any other code fails the check.

Keyword

If the monitor has a keyword, the page must contain it exactly, with the same capital letters. A missing keyword fails the check.

Response time

If the monitor has a threshold, a slower answer marks it Degraded. It still counts as up.

TLS certificate expiry

For HTTPS monitors the worker reads when the certificate expires and warns 30 days and again 7 days before.

A failed check records why: timeout, 5xx, unexpected status, missing keyword, DNS, TLS or connection. Raw checks are kept for 7 days, then summed up per hour and per day.
