Maintenance windows

Planned work should not look like an outage. During a maintenance window checks keep running, but no alerts are sent and downtime does not count against uptime.

  • Scheduled: pick a start and an end in the calendar.
  • Quick: one click starts maintenance for 15, 30 or 60 minutes, for example right before a deploy.

While a window is open the status page shows the monitor as Maintenance.
