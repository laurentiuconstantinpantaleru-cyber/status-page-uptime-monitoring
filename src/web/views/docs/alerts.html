Alerts and escalation

When an incident opens, the primary contacts get one alert by email or Telegram, and one more when it is resolved: no alert for every failed check.

Each alert says which monitor and URL failed, the HTTP code or error, the cause, how long since the last good check, and has a link to acknowledge it.

Escalation

If nobody acknowledges the alert within 15 minutes, the secondary contact is alerted too. Organization admins can set this time up to 1 hour. Acknowledge from the link in the alert or in the dashboard.
